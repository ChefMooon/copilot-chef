# Documentation Archive

This folder contains historical planning and research documents that are not the current source of truth for the app.

Use these for project history and rationale only.

Active source-of-truth docs are indexed in [`docs/STRUCTURE.md`](../STRUCTURE.md).

Archive categories:

- `plans/` — completed feature work and superseded architecture proposals
- `copilot/` — paused Copilot integration plans and research
- `research/` — historical technical research
- The archive root — retired operational guides

The active application is Local Recipe Book. Historical documents may retain `Copilot Chef`, `copilot-chef`, or older source paths because they describe the implementation and terminology that existed when they were written.
